= 添加Google Cloud NetApp Volumes系统
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
设置服务帐户后，在NetApp Console中添加Google Cloud NetApp Volumes系统，以便您可以查看Google Cloud NetApp Volumes实例。

此订阅的云卷显示在系统中。


NOTE: 如果您在多个 Google Cloud 项目中拥有订阅和卷，则需要为每个项目执行此任务。

.开始之前
在为每个项目添加系统之前，请确保：

* Google Cloud 服务帐户已设置，其凭据可在 NetApp Console 中使用。有关详细信息，请参见link:task-set-up-gcnv.html["设置Google Cloud NetApp Volumes"]。
* 您在 NetApp Console 中拥有 Google Cloud NetApp Volumes 管理员或查看者角色。有关详细信息，请参见 link:task-add-roles.html["分配Google Cloud NetApp Volumes角色"]。


.步骤
. 从NetApp Console菜单中，选择“*存储*”，然后选择“*管理*”。
. 在系统页面上，选择*添加系统*并选择*Google Cloud Platform*。
. 在 * Google Cloud NetApp Volumes* 旁边，选择 *Discover*。
. 提供有关您的NetApp Volumes 订阅的信息：
+
.. 输入您想要使用的系统名称。
.. 从*凭据*中，选择要使用的 Google Cloud NetApp Volumes 凭据。
+
如果未列出任何凭据，请先添加 Google Cloud NetApp Volumes 凭据，然后再继续。在凭据可用之前，项目和区域选择不可用。

.. 在*区域*中，为 Google Cloud NetApp Volumes 选择一个受支持的区域。
.. 选择*发现*。




.结果
控制台显示您的Google Cloud NetApp Volumes系统。
